# Лабораторна робота №6 — варіант 8

Проєктування мікропроцесорних систем на базі Raspberry Pi. Робота з GPIO та ОС Raspbian.

## Завдання 1 — керування двигуном у Proteus

Розроблено схему керування двигуном постійного струму через реле за допомогою Raspberry Pi 3.

- Керуючий вихід: GPIO9 (BCM), фізичний контакт 21.
- Живлення котушки реле та двигуна: 5 В.
- Драйвер реле: транзистор BC547, резистор бази 1 кОм і захисний діод 1N4007.
- Цикл роботи: увімкнення на 800 мс, вимкнення на 3000 мс, повторення.

## Завдання 2 — робота з Raspbian і вебкамерою

У VirtualBox створено віртуальну машину зі встановленою ОС Raspbian. Встановлено Midnight Commander, VLC, scrot та OpenCV 4.5.1.

Вебкамеру підключено до віртуальної машини та перевірено у VLC. Розроблено програму `my_face.py`, яка відображає відео з камери та виявляє обличчя за допомогою Haar-класифікатора. Знайдені обличчя виділяються зеленими рамками. Знімки результатів збережено утилітою scrot.

## Файли

- `Lab6_Spiavk.pdsprj` — проєкт Proteus зі схемою та вбудованим кодом керування двигуном.
- `main.py` — окрема копія Python-коду для завдання 1.
- `my_face.py` — Python-програма для перегляду відео та виявлення обличчя в завданні 2.

## Запуск

Для завдання 1 відкрити `Lab6_Spiavk.pdsprj` у Proteus із підтримкою Raspberry Pi та запустити симуляцію.

Для завдання 2 виконати в терміналі Raspbian:

```bash
python3 my_face.py
```

Перед запуском закрити VLC, щоб звільнити камеру. У вікні програми клавіша **D** вмикає або вимикає виявлення обличчя, **Q** завершує роботу. Клавіші натискати в англійській розкладці.
