# Лабораторна робота №6 — варіант 8

Керування двигуном постійного струму через реле за допомогою Raspberry Pi 3 у Proteus.

## Параметри

- Керуючий вихід: GPIO9 (BCM), фізичний контакт 21.
- Живлення котушки реле: 5 В.
- Драйвер: BC547, резистор бази 1 кОм, захисний діод 1N4007.
- Цикл збереженої програми: увімкнення на 800 мс, вимкнення на 3000 мс, повторення.

## Файли

- `Lab6_Spiavk.pdsprj` — проєкт Proteus зі схемою та вбудованими файлами програми.
- `main.py` — окрема копія Python-коду з проєкту.
